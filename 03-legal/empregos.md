# empregos

## Regras gerais

{% hint style="warning" %}
**Proibido** usar veículos de serviço para fins indevidos, incluindo:

* Caminhão de lixeiro para farm de facção ou ilegal;
* Circular/passear sem necessidade com veículo de trabalho.
{% endhint %}

{% hint style="warning" %}
**Proibido** usar viaturas/oficiais para fins pessoais (PM, Civil, GCM, Hospital, Mecânica, Bombeiros etc.), inclusive descaracterizadas e locomoção fora de serviço.
{% endhint %}

## Responsabilidade

* Ao fim do expediente, guarde o veículo na **garagem mais próxima**.
* Dano ou infração = responsabilidade de quem usou.

{% hint style="danger" %}
Violação pode gerar punição severa (STAFF avalia caso a caso).
{% endhint %}
