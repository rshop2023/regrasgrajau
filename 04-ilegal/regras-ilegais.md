# regras ilegais

## REGRA LOTEAR

* **Proibido** saquear policiais em **ações de rua**.
* **Permitido** saquear policiais em **favelas / QGs**.
* Em assaltos blipados: ver tabela em [Assaltos blipados](/broken/pages/8aaff8eaa80b72a058ffa466faeba200136fcb96) (alguns locais liberam loot).
* Em airdrop: [Airdrop](/broken/pages/9985535a153e015eb8cf7cc27ce73afb6e8a21b2) (loot de polícia **proibido**).
* Nos locais que permite lootear policia deve pegar somente itens militar exemplo, armas,munições,colete,algemas. Proibido pegar itens pessoas como celular,dinheiro limpo,kit médico.
* É permitido lootear itens de pessoas mortas, exceto em áreas safe, onde o loot é proibido.

## Gerais

* Proibido atirar de dentro de **qualquer veículo blindado**.
* Permitido **apenas 1 pessoa** no porta do veículo.

## Fuga (resumo)

Regras completas: [Fugas e perseguições](/broken/pages/cfc63ebbef8acba662ebb925a8eb081112e23956).

* Fuga para casa é permitida; a polícia pode continuar dentro.
* Após voz de parada, podem tentar escapar até captura ou despiste.
* Fuga a pé: polícia pode imobilizar com cabeçada / SHIFT+E. Soco à distância para alcançar = **power gaming**.
* Fuga para favela: permitido lootear polícia; qualquer armamento nessas áreas.

## Códigos policiais

Códigos **3** e **5** estão só em [Regras policiais](file:///0125121/03-legal/regras-policiais.md).

## Roubo (quando a viatura chega)

* Bandido pode **terminar** o roubo; polícia aguarda.
* Se demorar **mais de 1 minuto** para iniciar a fuga, a guarnição pode imobilizar e prender.

## ROUBO DE VEICULOS

Permitido usar lockpick ou pegar veiculos **abandonados** nas ruas mesmo fora de horario de assalto

Proibido Usar Lockpick ou Furtar veiculos em safezones

Proibido Roubar o veiculo abandonado caso tenha alguém perto com vida

## Guerra entre facções

{% stepper %}
{% step %}
### Obrigatório declarar guerra

Não sair matando antes.
{% endstep %}

{% step %}
### Quem declara

Quem declara é quem quer “cobrar”.
{% endstep %}

{% step %}
### Objetivo e participação

Objetivo claro e, se possível, provas. Quem desmaiar/morrer (combate, acidente, polícia etc.) fica **fora da guerra** até o fim.
{% endstep %}

{% step %}
### Após morrer na guerra

* Longe de quem ainda está em guerra;
* Longe da base da facção até terminar;
* Fora da rádio e do grupo;
* Morto **não** passa informação.
{% endstep %}

{% step %}
### Guerra iniciada na rua

Cobrada na rua.
{% endstep %}

{% step %}
### Guerra iniciada na favela

Cobrada na favela.
{% endstep %}

{% step %}
### Outro local

Líderes podem combinar outro local com o Responsável Ilegal.
{% endstep %}

{% step %}
### Corpos da própria facção

Resgate liberado, mas mesmo levantado continua **fora** da guerra.
{% endstep %}

{% step %}
### Facção rival

Desovar / flaming = punição.
{% endstep %}
{% endstepper %}

## Invasão

Pode ocorrer após incidente na organização (fuga de fora para dentro, QRU de disparo, QRU de roubo etc.).

{% stepper %}
{% step %}
### Baú

Polícia **não** mexe no baú.
{% endstep %}

{% step %}
### Defesa

Bandidos **não** são obrigados a defender.
{% endstep %}

{% step %}
### Contingente policial

Quem estiver no momento.
{% endstep %}

{% step %}
### Aviso de invasão

Polícia avisa invasão pelo **190** com pelo menos **5 minutos** de antecedência.
{% endstep %}

{% step %}
### Porte de arma

Portar arma dentro da organização **não** justifica invasão sozinha.
{% endstep %}
{% endstepper %}
