## Policia

Esta Proibido Policia Participar da ação airdrop
{% endstep %}

{% step %}
## Armamentos

**Qualquer** armamento permitido.
{% endstep %}

{% step %}
## Área de combate

Troca de tiros **somente dentro** da área do Airdrop. Proibido sair da zona para continuar o confronto.

Exemplo: Airdrop no Pier → proibido levar o tiroteio até o Estacionamento Vermelho.
{% endstep %}

{% step %}
## Loot entre jogadores

Enquanto a **caixa estiver ativa**, permitido lootear abatidos **dentro** da área.
{% endstep %}

{% step %}
## Encerramento

Após coletar a caixa, a ação **encerra**. A partir daí:

* Proibido lootear qualquer jogador;
* Proibido apreender itens;
* Proibido apreender veículos relacionados à ação.
{% endstep %}

{% step %}
### Após Abatido

Após ser morto por alguem devera esperar a caixa ser looteada após isso podera chamar Paramedico ou Voltar para o Aeroporto.

Proibido após ser morto voltar para a ação
{% endstep %}
