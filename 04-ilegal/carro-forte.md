# Carro Forte

{% stepper %}
{% step %}
## Defesa pela polícia

A PM pode defender o Carro forte.
{% endstep %}

{% step %}
## Loot em policiais

**Proibido** lootear policiais durante toda a ação do Carro forte.
{% endstep %}

{% step %}
## Armamentos

**Qualquer** armamento permitido.
{% endstep %}

{% step %}
## Área de combate

Troca de tiros **somente dentro** da área Vermelha. Proibido sair da zona para continuar o confronto.

Exemplo: Carro Forte no Pier → proibido levar o tiroteio até o Estacionamento Vermelho.
{% endstep %}

{% step %}
## Loot entre jogadores

Enquanto a **Estiver ativa a zona de risco**, permitido lootear abatidos **dentro** da área.
{% endstep %}

{% step %}
## Apreensão policial

Policiais podem apreender somente itens ilegais

**Proibida** apreensão de veículos durante a ação.
{% endstep %}

{% step %}
## Encerramento

Após dar como Roubo Concluido:

* Proibido lootear qualquer jogador;
* Proibido apreender itens;
* Proibido apreender veículos relacionados à ação.
{% endstep %}

{% step %}
### Após Abatido

Após ser morto por alguem devera esperar a ação acabar após isso podera chamar Paramedico ou Voltar para o Aeroporto.

Proibido após ser morto voltar para a ação
{% endstep %}
{% endstepper %}
